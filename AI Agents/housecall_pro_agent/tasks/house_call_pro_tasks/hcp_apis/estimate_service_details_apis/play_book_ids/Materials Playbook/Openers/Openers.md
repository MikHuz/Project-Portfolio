# Garage Door Openers

This file defines all the BUSINESS provided garage door openers with the installation fee included as part of its price. You use this file always if the task asks for an opener and doesn't specify if its from a customer . If the task rewuests explicitly asks or mentions for a customer provided openers DO NOT parse from this file , go to the "Services" playbook.

This section is divided into three main openers "7foot rail", 8 foot rail, 10+ foot rail, and "Side Openers". 7 foot is default for 90 percent of rewuests, but refer to your markdown instructons under "playbook.md" to understand which section to use. IF unsure, always  use 7 foot.
