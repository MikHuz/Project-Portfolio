# plank_door_windows.md
This file defines the ids for the actual windows for the designs (no or short windows), so short windows on plank doors


### RULE (IMPORTANT)
These line_items MUST ONLY be used when:
- The request explicitly asks for "Windows on top", OR
- No window location is specified (default assumption = TOP when windows are requested)

If the request specifies any other window location (e.g., bottom, middle, none), these IDs must NOT be used.
